# SEKHEM — "Give Every Door a Name" (Keynote Deck)

**Generator #10 · Presentation Designer · Apple Presentation Designer**
*Audience: security teams, educators & potential contributors · 20 minutes · Objective: inspire + persuade (awareness & adoption)*

---

## 1. NARRATIVE ARCHITECTURE

**Story arc (hero's journey applied):**
- **Status quo:** Knowledge is scattered and gated — the hero is lost in a desert of PDFs.
- **Call to adventure:** A practitioner needs one answer, fast, with no logins.
- **Guide:** SEKHEM hands them a codex — a map of 24 hunting grounds.
- **Transformation:** Blind spots become named doors; reference becomes action.
- **Return with the elixir:** An open, community-maintained codex everyone can use and extend.

**Opening hook (first 60s):** A terminal-like black slide. One line of gold text types in:
*"Every door has a name."* Beat. *"Most tools make you guess which."* Then the wordmark rises.

**Three core messages:**
1. **Depth without the dig** — 24 domains, 124 pages, 104 sealed PDFs, one search.
2. **Trust by architecture** — no logins, no telemetry, local-first, MIT-licensed.
3. **Open by conviction** — built by the community, attributable, forkable.

**Closing CTA:** "Enter the codex. Name your next door." → `sabriigsxr.github.io/sekhem/` + GitHub.

## 3. VISUAL DESIGN SYSTEM

- **Palette:** obsidian `#0b0908` backgrounds (impact), papyrus `#f3ecdc` for data slides (clarity), gold `#c9a227` accents, faience `#1fb6a6` for data, carnelian `#8c2f2f` for problem slides only.
- **Typography:** Cinzel Decorative (display 48pt), Cinzel (headline 30pt), Spectral (body 16pt), JetBrains Mono (data/labels 12pt).
- **Imagery:** abstract Egyptian geometry (pyramids, cartouche, Eye of Horus), no stock photography; architect portrait only on S16.
- **Data viz:** flat bars/lines in gold + faience, mono labels, no gradients except hero glow.
- **Iconography:** lucide line icons, 2px stroke, consistent 24px grid.

---

## 4. ASSET SPECIFICATIONS

- **Images:** 1 architect portrait (≥1024px), 5 vector scene illustrations (pyramids, cartouche, eye, stele, map), 1 QR to site.
- **Chart data:** use real figures only (24 domains, 124 docs, 104 PDFs, 13 contributors); mark growth curve as illustrative.
- **Icons (15):** shield, search, scroll, vault, checklist, pyramid, eye, key, lock, github, sparkle, download, compass, network, book.
- **Animation:** Keynote "Magic Move" for relic transitions; 0.8s rise, 0.12s micro; respect reduced motion for recorded versions.

---

## 5. PRESENTER GUIDELINES

- **Pacing:** Problem 4 min · Codex 10 min · Invitation 6 min.
- **Transition scripts:** "So we saw the scattered map — now let's name the doors."
- **Interaction moments:** S4 poll ("Who's lost hours to a gated wiki?"), S18 Q&A prompt.
- **Backup slides (5):** deeper agent-readiness detail, accessibility approach, migration/attribution, contributor workflow, live `⌘K` demo.

## 6. HANDOUT MATERIALS

- **One-pager:** front = wordmark + tagline + 3 stats; back = URL, GitHub, "use/star/contribute."
- **Leave-behind deck:** 8-slide simplified version (S1, S3, S6, S8, S9, S12, S18, S19).

*Designed for emotional impact: every slide earns its place by advancing the single idea — knowledge, named.*
